📁 Project Overview
The practicals are organized by their technical focus:

1. Enterprise JavaBeans (EJB) & Multi-tier Architecture
  Projects: ecomm-er, ecomm-cdi <br>
   #. Focus: Enterprise-grade business logic.<br>
   #. Key Skills: * EJB: Utilizing Session Beans (Stateless, Stateful) to manage business transactions.<br>
   #. CDI: Decoupling services using Dependency Injection, custom annotations (@SMS, @Email), and modular design patterns.<br>
   #. Multi-Module: Structuring projects as Maven pom aggregators with distinct core, ejb, web, and ear modules.<br>

2. Distributed Computing
  Projects: rmi (RMIServer & RMIClient), corba<br>
   #.  Focus: Remote object communication.<br>
   #.  Key Skills: * RMI: Establishing remote method invocation between separate JVMs. <br>
   #.  CORBA: Using IDL (Interface Definition Language) for platform-independent, language-neutral object interoperability.<br>

3. Asynchronous Messaging (JMS/ActiveMQ)
  Projects: activemq, JMS/jms-webapp<br>
   #.Focus: Asynchronous, event-driven communication.<br>
   #.Key Skills: * Queues: Point-to-point messaging for reliable order processing.<br>
   #.Topics: Pub/sub patterns for inventory broadcasts.<br>
   #.MDBs: Implementing Message-Driven Beans to react automatically to incoming messages.<br>
